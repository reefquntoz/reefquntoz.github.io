### Applied AIML 2 - Assignment 3

**Transformer From Scratch for IMDb Sentiment Analysis**

Built a 4-layer Transformer encoder from scratch in PyTorch for movie review classification, achieving **86.64% accuracy** on the IMDb test set.

**Key Highlights:**

*   Implemented multi-head self-attention mechanism (4 heads)
    
*   Custom word-frequency tokenization (20,000 vocabulary)
    
*   Positional encoding with sinusoidal embeddings
    
*   Training with Adam optimizer (86.64% test accuracy)
    

**Technologies:** PyTorch, Python, Machine Learning, NLP
